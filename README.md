# 📚 NovelVerse

**NovelVerse** is a social reading platform where readers can discover stories, follow authors, and interact with a community of book lovers.

The platform is being built with support for **AI-generated novels and digital reading experiences**, with plans to expand into multimedia storytelling.

## ✨ Features

* 📖 Discover and read novels
* ✍️ Author profiles and publishing
* ❤️ Like and comment on chapters
* 🔖 Bookmark stories
* 👥 Follow authors
* 📈 Track reading progress
* 🤖 AI-generated story content
* 🎬 Future support for AI-powered story videos

## 🛠️ Tech Stack

### Frontend

* Next.js

* Tailwind CSS

### Backend

* Node.js
* Express.js
* PostgreSQL
* Prisma ORM

### Infrastructure

* Docker

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd novel-verse
```

Start the development environment:

```bash
docker compose up -d
```

Then start the frontend and API from their respective directories.

## 🎯 Vision

NovelVerse aims to bring **readers, authors, and AI-powered storytelling together in one platform**, making digital storytelling more interactive and social.
